# SOL · 太阳系

> 一颗恒星，八颗行星，以及它们之间漫长的沉默。

一个跑在浏览器里的太阳系模型。真实星历（开普勒轨道 + 儒略周期线性变率）驱动，
程序化生成的行星表面与星空，零外部素材、零网络请求、离线可用。

---

## 快速开始

```bash
npm install
npm run dev      # http://127.0.0.1:5173
```

打包：

```bash
npm run build    # 产物在 dist/，可直接用任意静态服务器托管
npm run preview
```

## 它是怎么算的

### 轨道

行星位置由六个轨道根数决定（半长轴 `a`、偏心率 `e`、倾角 `i`、平黄经 `L`、
近日点黄经 `peri`、升交点黄经 `node`），取值来自 JPL 的 1800–2050 近似星历表
（J2000 历元），并带有每儒略世纪的变化率。任意时刻的平近点角由线性变率推进，
再用牛顿迭代解开普勒方程 `M = E − e·sin E`，最后按轨道平面旋转到黄道坐标系。

这不是 N 体实时积分——真太阳系里太阳占了 99.86% 的质量，行星互引力可以忽略，
硬算反而会因为初值误差让轨道乱飘。开普勒模型既准确又便宜。

卫星（月球、木卫、土卫、海卫一……）用同样的思路，只是把母天体当作中心。

### 坐标

内部用天文黄道坐标系（黄道面 = XY，北黄极 = +Z），场景里绕 X 轴 −90° 摆正，
于是场景的 +Y 就是北黄极，轨道平面就是地平面。`1 世界单位 = 1 AU = 100 单位`。

### 尺度

真实比例下，太阳直径是地球的 109 倍，而地球轨道半径是太阳直径的 215 倍——
地球在海王星轨道上只是 6467 倍远的一个点。所以：

- **轨道半径**线性、真实，按 AU 摆放；
- **天体半径**按类别夸大（太阳 16、地球 1.3、木星 5.2 单位），滑杆可连续调到真实比例；
- 相机用**对数深度缓冲**（`logarithmicDepthBuffer`）撑开 0.01 → 4,000,000 的深度范围。

### 表面

所有贴图都是 GPU 上一次性烘焙的程序化纹理，没有一张外部图片：

- 岩质行星：多层 simplex 噪声 + ridged 噪声做撞击纹理与极冠；
- 气态巨行星：纬度带 + 域扭曲湍流 + 大红斑；
- 地球：海陆掩膜 + 湿润度分布 + 极地冰盖，另有独立的**夜面城市灯光**与**云层**贴图；
- 冰质世界：亮暗两半 + 裂缝脊线；
- 太阳：米粒组织 + 黑子。

土星环是按真实环系分区（C/B/卡西尼缝/A/F）算出来的径向密度剖面，
并用解析圆柱阴影算出行星投在环上的影子。

小行星带与柯伊伯带在顶点着色器里解开普勒方程，4200 + 2600 个实例各走各的轨道；
另外叠了一层弥散尘埃盘（带柯克伍德空隙）。

## 结构

```
src/
  core/kepler.ts      开普勒方程、根数→坐标、轨道采样
  core/time.ts        儒略日、时间倍率预设
  data/bodies.ts      全部天体的物理数据与文案
  data/looks.ts       程序化贴图配色
  render/glsl.ts      共享噪声库
  render/textures.ts  表面/光环/尘埃的程序化生成
  render/materials.ts 行星、云、辉光、日冕着色器
  render/sky.ts       星空、银河带
  render/belts.ts     小行星带 / 柯伊伯带（GPU 开普勒）
  scene/SolarSystem.ts 场景总装与逐帧更新
  scene/CameraRig.ts  轨道相机、聚焦、跟随
  app.ts              时间轴、UI、开场运镜、拾取
```

## 数据来源

- 行星轨道根数与变化率：JPL Solar System Dynamics 近似星历表
- 物理量（半径、质量、温度、卫星数、发现年份）：IAU / NASA Planetary Fact Sheet
- 月球轨道进动率：标准平均运动根数

数值均取自公开的天文常数表，仅用于可视化演示。

代码可自由使用。数据为公开天文常量。
