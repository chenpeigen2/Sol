# SOL · 一起看太阳系

> 一颗恒星，八颗行星，以及它们之间漫长的沉默。

TypeScript + three.js + Vite 的纯前端交互太阳系。主要行星采用本地打包的高清影像，地球日夜面为 4K、其余主要表面为 2K；程序化材质作为后备。星空、土星环与彗星双尾仍为程序化生成，不依赖运行时外部 API。

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 静态产物 dist/
npm run preview    # 构建产物预览
```

需支持 WebGL2 的现代浏览器；辉光可在探索控制台关闭以减轻 GPU 负担。静态部署需通过 HTTP(S) 访问，不支持直接双击 HTML。

## 体验

- **电影巡游**：七个章节，游览地球、地月系统、木星卫星、木卫二、土星、海王星、冥王星系统。每站约 12 秒，有字幕、进度、上一站/下一站；手动操作相机会停止巡游。
- **探索天体**：搜索中文名、英文 ID 或拉丁名，直达全部 22 个天体，含 12 颗卫星。
- **视角预设**：近距离、黄道俯视、侧视、卫星系统；也可框选内太阳系或全太阳系。
- **时间旅行**：日期输入、正放/倒流、暂停、七档时间倍率。日期范围 1800–2050。界面显示 UTC；未处理 TT/UTC 的几十秒差异，不用于精密星历。
- **浪漫模式**：隐藏工具和标签，缓慢环绕当前视角。`C` 切换，`Esc` 退出。
- **写给你**：自定义 100 字寄语，仅保存在当前浏览器本地；文本按纯文本处理。
- **星空明信片**：导出当前 3D 场景 + 寄语 + 模拟日期为 PNG，不包含工具面板。
- **彗星双尾演示**：在探索控制台点“追寻彗星”，展示蓝色离子尾和弯曲金色尘埃尾。此为示意彗星，不是哈雷彗星或任何真实彗星的预报。
- **显示选项**：轨道、标签、运动轨迹、辉光、示意彗星；尺寸滑杆在真实几何尺寸和视觉夸张之间插值。浪漫模式隐藏轨道，退出恢复。
- **高清近景**：表面各向异性过滤、后处理目标 MSAA、薄层大气、独立云层与夜景；选中天体自动减速，退出恢复先前速度。

鼠标拖动旋转，滚轮缩放，右键平移；触屏单指旋转、双指缩放。空格暂停，`F` 切换跟随，`Esc` 退出面板/巡游/浪漫模式。连续点太阳三次有小彩蛋。

## 模型与边界

- 行星根数基于 JPL 的 J2000 近似根数及每世纪变率（参考：<https://ssd.jpl.nasa.gov/planets/approx_pos.html>），不是 N 体积分，也不作“角秒级精度”保证。
- 使用 `M = L − 近日点黄经` 求平近点角，再解 `M = E − e sin E`。单位为 AU，渲染映射为 **1 AU = 100 世界单位**。
- 行星轨道距离线性真实；真实尺寸端点使用 `真实半径 km / AU_km × 100`，卫星轨道端点也恢复真实距离。光点/标签仍有可读性下限，不代表真实角直径。
- 卫星相位和倾角是简化示意，非高精度卫星星历；不模拟食、潮汐、摄动或冥王星/冥卫一双星质心。
- 主要表面采用 Solar System Scope 影像集，基于 NASA 数据并包含颜色处理与缺失地形补全；不是逐张未经处理的航天照片。授权与改动见 [素材署名](public/textures/ATTRIBUTION.md)。程序化后备地形、其余卫星表面仍是艺术化示意。星点为种子随机生成，不是真实恒星目录。
- 天体转轴倾角用于表现季节感，但不含完整 IAU 自转极方向模型。
- 小行星带 4200 个、柯伊伯带 2600 个实例，GPU 求开普勒轨道。尘埃盘与彗星尾的亮度、密度都为艺术夸张。
- 土星环使用径向密度剖面及行星圆柱阴影近似（半影柔化）；天王星环为同一艺术化环纹理，并非真实环系复原。
- 物理数据是近似科普值，卫星数等会随新发现变化。

## 测试

```bash
npm test             # 开普勒方程、坐标路径一致性、比例检查、相机插值
npm run test:startup  # 首屏无原始控件闪现（需要 dev server）
npm run test:detail   # 高清贴图解码、canvas 像素、移动端与失败回退检查
npm run test:browser  # 需要 dev server + 系统 Edge；BROWSER_CHANNEL 可改 chrome
```

浏览器测试覆盖桌面与 390px 手机布局：搜索卫星、视角、轨迹开关、真实尺寸比、日期设置、倒流、巡游、寄语纯文本安全、PNG 下载、效果开关、控制台错误。截图写入忽略的 `test-results/`。

## 结构

```text
src/core/              开普勒力学、儒略日、缓动
src/data/              天体数据、程序化配色
src/render/            材质、噪声、表面生成、星空、带状小天体、彗星
src/scene/             场景与相机飞行/跟随
src/ui/Experience.ts   探索控制台、巡游、寄语与遥测 UI
src/app.ts             时间/选择/场景编排、PNG 合成
src/polish.css         视觉打磨层（字体、层次、留白）
public/textures/        本地高清影像与 CC BY 4.0 署名
scripts/prepare-textures.mjs  下载、缩放、WebP 转换（非运行必需）
```

## 素材许可

主要天体影像：Solar System Scope / INOVE，CC BY 4.0，已缩放并转换为 WebP。页面与导出的 PNG 均附署名。参见 `public/textures/ATTRIBUTION.md`；素材更新命令：`node scripts/prepare-textures.mjs`。

## 部署

构建产物是纯静态文件，用任意静态服务器托管即可（需通过 HTTP 访问，不能双击 HTML）。
当前部署为独立 Nginx 容器，映射 4174 端口，只读挂载 `/srv/sol/releases/<版本>`：

```bash
docker rm -f sol-web
docker run -d --name sol-web --restart unless-stopped \
  -p 4174:80 -v /srv/sol/releases/<版本>:/usr/share/nginx/html:ro nginx:1.27-alpine
```
